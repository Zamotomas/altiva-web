# Guía de Instalación y Ejecución

---

## Requisitos previos

Node.js,versión 18 o superior recomendada [Node.js](https://nodejs.org/).

verificar instalacion:

```bash
node -v
npm -v
```

---

### Instalar dependencias
Ejecuta el npm en la raíz del proyecto para instalar los paquetes necesarios:

```bash
npm install
```
---

## Ejecutar el proyecto

Para iniciar el servidor de desarrollo local con Vite:

```bash
npm run dev
```

URL indicando en la consola (`http://localhost:5173`).
